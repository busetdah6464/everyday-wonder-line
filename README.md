## The entry

> The escalator handrail outruns the steps, so for one whole floor my hand arrives before the rest of me does.

One sentence, 108 characters. A small everyday moment — riding an
escalator — turned strange: the handrail really does move a little faster
than the steps, so for a whole floor your hand is travelling ahead of you.

## How it works

`main.py` (Python 3, standard library only, deterministic, no network,
no randomness) writes the sentence to `/output/entry.txt`:

```sh
python3 main.py
cat /output/entry.txt
```

## Build notes

- The entry is a single original sentence, written from scratch for this
  bounty, within the competition's 1–200 character gate. It is grounded in
  something real and specific: escalator handrails are built to run
  slightly faster than the steps, so the split-second lead is physical,
  not invented.
